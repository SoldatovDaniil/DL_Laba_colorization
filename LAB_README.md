# Colorful Image Colorization

Данный репозиторий подготовлен в рамках выполнения лабораторной работы по курсу «Глубокое обучение». За основу взят проект, реализующий автоматическую колоризацию чёрно-белых изображений с использованием предобученных свёрточных нейросетей.

Ссылка на оригинальный проект: [richzhang/colorization](https://github.com/richzhang/colorization)

## Краткое описание окружения проекта

Для обеспечения переносимости, воспроизводимости и стабильного запуска проекта на различных платформах окружение упаковано в Docker-контейнер:

- **Базовый образ:** `python:3.10-slim` (минималистичный дистрибутив Linux Debian).
- **Фреймворк:** PyTorch. Поддерживается запуск на CPU.
- **Модели:** ECCV16 и SIGGRAPH17 — предобученные модели колоризации. Веса скачиваются автоматически на этапе сборки Docker-образа, что позволяет запускать контейнер в офлайн-режиме.
- **Дополнительные зависимости:** numpy, scikit-image, matplotlib, Pillow.
- **Тест:** использует цветные изображения из репозитория (ImageNet val), подаёт модели только яркость и сравнивает результат с цветным оригиналом (PSNR, SSIM, ошибка по ab) и с «серым» baseline без раскраски; seed фиксирован.

## Инструкция по запуску проекта через Docker

Клонируйте репозиторий проекта:

```bash
git clone https://github.com/SoldatovDaniil/DL_Laba_colorization.git
cd DL_Laba_colorization
```

### 1. Сборка Docker-образа

Веса моделей скачиваются автоматически во время сборки:

```bash
docker build -t colorization .
```

### 2. Запуск теста на корректность и воспроизводимость

```bash
docker run --rm colorization
```

При запуске будет вызван `RunCheckerTest.py`, который выполнит следующие шаги:

1. Зафиксирует random seed (`seed=42`) для numpy и torch.
2. Загрузит обе предобученные модели (eccv16 и siggraph17).
3. Проверит форму выходного тензора: `(1, 2, 256, 256)` — 2 канала ab.
4. Возьмёт 3 цветных изображения `imgs/ILSVRC2012_val_*.JPEG`, оставит от них только канал L и прогонит через обе модели.
5. Для сравнения посчитает «серый» baseline — то же изображение без цвета (ab = 0).
6. Вычислит средние по изображениям метрики относительно цветного оригинала: PSNR, SSIM, MAE по каналам ab и насыщенность |ab|.
7. Проверит для каждой модели: PSNR > 18 дБ, SSIM > 0.75, ошибка по ab хотя бы на 25% меньше, чем у серого baseline, средний |ab| > 5 (модель действительно добавляет цвет).
8. Проверит воспроизводимость — два прогона дают идентичный результат.

Ожидаемый результат (среднее по 3 изображениям):

| Модель | PSNR, дБ | SSIM | ab MAE |
|---|---|---|---|
| серый baseline | 16.34 | 0.812 | 21.31 |
| eccv16 | 20.29 | 0.845 | 13.21 |
| siggraph17 | 19.61 | 0.844 | 13.53 |

Модели без обученных весов (`pretrained=False`) этот тест не проходят.

### 3. Колоризация произвольного изображения (опционально)

```bash
docker run --rm -v $(pwd)/imgs:/app/imgs -v $(pwd)/output:/app/output \
    colorization python demo_release.py -i imgs/ansel_adams3.jpg -o output/result
```
